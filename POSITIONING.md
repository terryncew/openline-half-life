# OpenLine positioning

## Category

**You own the job. The model is the console.**

OpenLine is a cross-platform save file for AI agents. It lets an agent save the verified state of a job on one model, load that state on another, and continue with the record intact.

“Same point” means the same disclosed job state: commitments, constraints, evidence, confirmed outcomes, unresolved questions, contradictions, and receiver decisions. OpenLine does not claim to transfer model weights, hidden thoughts, private chain of thought, or a provider's internal memory.

## Four one-sentence versions

**Nontechnical:** OpenLine lets an AI agent save its progress on one model and continue the same job on another.

**Developer:** OpenLine packages verified job state into a portable handoff that another model can load and independently check before continuing.

**Buyer:** OpenLine reduces provider lock-in by letting governed agent work survive a model change without treating old evidence as fresh permission.

**Resharer:** Save the job on one model, pick it up on another, and keep the proof intact.

## Stack under the metaphor

OpenLine receipts record what happened. Half-Life makes the verified save file smaller without changing receiver decisions. Verified Model Swap proves another model can load it. Receipt Gate decides what the transferred evidence earns. Verified Commit gives the receiving model fresh permission for one exact action.

Compression and lower context cost are supporting benefits. They are not the category claim.
